Imágenes en HTML

Para poner una imagen simple en una página web, utilizamos el elemento <img>.
Se trata de un elemento vacío (lo que significa que no contiene texto o etiqueta de cierre). El atributo src es obligatorio y contiene la ruta que apunta a la imagen que quieres poner en la página, que puede ser una URL relativa o absoluta, de la misma forma que el elemento <a> contiene los valores del atributo href.

Por ejemplo si nuestra imagen se llama dinosaur.jpg, y está en la ubicación habitual donde alojamos las imágnes: (resources/img), escrbiriamos el siguiente código para mostrar la imagen 

                     
    <img src="resources/img/dinosaur.jpg"/>

El resultado sería:

Puedes incrustar la imagen usando la URL absoluta, por ejemplo:

                     
            <img src="https://www.example.com/images/dinosaur.jpg">

Pero esto no tiene sentido, solo hace que el navegador trabaje más buscando la dirección IP desde el servidor DNS cada vez, etc. Casi siempre mantendrás las imágenes para tu sitio web en el mismo servidor de tu HTML.

Advertencia: La mayoría de imágenes tienen derechos de autor. No muestres una imagen en tu página web a menos que:

  1. seas dueño de la imagen
  2. tengas permiso escrito explícito del dueño de la imagen o
  3. tengas suficientes pruebas de que la imagen es de dominio público.

El incumplimiento de las normas de los derechos de autor es un acto ilegal y poco ético. Por lo tanto, no apuntes nunca tu atributo src a una imagen que esté alojada en un sitio web si no tienes el permiso para hacerlo. Esto se llama hotlinking. Asimismo es ilegal robar el ancho de banda de alguien. Además, ralentiza tu página y te deja sin control sobre la imagen si la eliminan o reemplazan por otra que incluso podría resultar embarazosa.

Texto alternativo

El próximo atributo que veremos es alt. Su valor debe ser una descripción textual de la imagen para usarla en situaciones en que la imagen no puede ser vista/mostrada o tarde demasiado en mostrarse por una conexión lenta a internet. Por ejemplo, nuestro código anterior podría modificarse así: 

 
        <img src="resources/img/dinosaur.jpg"
        alt="La cabeza y el torso de un esqueleto de dinosaurio;
        tiene una cabeza grande con dientes largos y afilados"/>

Para probar el efecto de la etiqueta alt, escribe mal el nombre del archivo al crear la etiqueta y observa que pasa al visualizar la página.

Usamos un texto alternativo por las siguientes razones:

  • El usuario tiene alguna discapacidad visual y utiliza un lector de pantalla para leer el contenido de la web. De hecho, disponer de texto alternativo para describir las imágenes es útil para la mayoría de los usuarios.
  • Como ya hemos dicho anteriormente, es posible que se haya escrito mal el nombre del archivo o su ruta.
  • El navegador no admite el tipo de imagen. Algunas personas aún usan navegadores de solo texto, como Lynx, que muestran el texto del atributo alt.
  • Quieres que los motores de búsqueda puedan utilizar este texto. Por ejemplo, los motores de búsqueda pueden hacer coincidir el texto alternativo con la consulta de búsqueda.
  • Los usuarios han desactivado las imágenes para reducir el volumen de transferencia de datos y de distracciones. Esto sucede especialmente en teléfonos móviles y en países en que el ancho de banda es limitado y caro.

Titulo en las imágenes

Al igual que con los enlaces, también puedes añadir atributos title a las imágenes para proporcionar más información de ayuda si es necesario. En nuestro ejemplo, podríamos hacer esto: 

 
    <img src="resources/img/dinosaur.jpg"
    alt="La cabeza y el torso de un esqueleto de dinosaurio; 
    tiene una cabeza grande con dientes largos y afilados" 
    width="250" 
    title="Exposición de un T-Rex en el museo de la Universidad de Manchester."/>

Comentar imágenes con figure y figcaption

HTML5 incluye dos nuevas etiquetas <figure> y <figcaption> que permiten vincular una figura con su pie de imagen. El elemento <figure> actua de contenedor semántico para la imagen y el elemento <figcaption> dice al navegador, o a alguna tecnología de apoyo, que el texto que contiene describe la imagen que está contenida en el elemento. Ejemplo de uso: 

    
<figure>
    <img src="resources/img/dinosaur.jpg"
        alt="La cabeza y el torso de un esqueleto de dinosaurio;
            tiene una cabeza grande con dientes largos y afilados" width="400"
        height="341">

    <figcaption>
    Exposición de un T-Rex en el museo de la Universidad de Manchester.
    </figcaption>
</figure>

Imágenes de fondo CSS

También puedes usar CSS para insertar imágenes en páginas web . La propiedad CSS background-image y las demás propiedades background-* se usan para controlar la colocación de la imagen de fondo. Por ejemplo, para poner la imagen del dinosaurio como imagen de fondo de los párrafos que queramos, usando una clase CSS para ello. Podemos definir la clase CSS fondodinosaurio asi: 

        
            .fondodinosaurio{
                background-image: url(../img/dinosaur.jpg);
            }
Y despues crear un párrafo con el atributo class igual a "fondodinosaurio" 
        
           <p class="fondodinosaurio"> 
           </p>

Si escribes algo de texto en el párrafo observarás que la imagen de fondo comienza a aparecer. Sigue escribiendo y la imagen de fondo se sigue mostrando para ocupar todo el párrafo. Si solo quisieras mostrar la imagen, porque ésta no aporta contenido semántico al texto y solo es decorativa, el contenedor de la misma debe tener el suficiente espacio para contenerla. Puedes emplear algunas propiedades adicionales CSS para lograr que la imagen se muestre proporcionada dentro de la altura que decidas que de debe tener. A continuación se muestra la regla CSS necesaria para conseguir mostrar una imagen como imagen de fondo en un párrafo y que está tenga una altura de 200px. 

        
            .fondodinosaurio2{
                background-image: url(../img/dinosaur.jpg);
                background-repeat: no-repeat;
                background-size:contain;
                height: 200px;
            }
Basta ahora el siguiente código para que la imagen se muestre como imagen de fondo de un párrafo cuyo atributo class es "fondodinosaurio2". Aunque el párrafo no tenga ningún contenido la imagen se mostrará, porque hemos forzado una altura de 200px. 
        
           <p class="fondodinosaurio2"> 
           </p>

Video y audio

Video

Puedes incrustar video fácilmente en tu web usando el elemento HTML5 <video>. Crea una carpeta videos en tu carpeta resources, copia los videos que se adjuntan y añade el siguiente código a tu página: 

                        
        <video src="resources/videos/videolocal.mp4" controls 
        width="320" height="240"></video>

Los elementos a destacar son:
src: Contiene una ruta al video que deseas incrustar. Funciona de la misma manera. Los atributos width y height definen el ancho y alto del marco en el que se mostrará el video.

controls: Los usuarios deben ser capaces de controlar la reproducción de video y audio (esto es especialmente crítico en personas que padecen epilepsia). Se debe utilizar el atributo controls para incluir la interfaz de control del browser, o construir la nuestra utilizando la JavaScript API apropiada. Como mínimo la interfaz debe incluir una manera de empezar y terminar la reproducción, y ajustar el volumen.

Incrustar video de youtube

Podemos compartir en nuestra web un video de youtube mediante el uso del elemento iframe. Un elemento iframe representa un contexto de navegación incrustado, permitiendo incluir otra página html dentro de la actual. Youtube en sus videos añade un enlace "compartir" mediante el cual podéis copiar el elemento iframe necesario para que el video se incruste en vuestra página. A continuación se muestra un video del mejor guitarrista de la historia del flamenco. 

            
    <iframe width="80%" 
    height="315" 
    src="https://www.youtube.com/embed/2oyhlad64-s" 
    frameborder="0"
    allow="accelerometer; 
    autoplay; clipboard-write; 
    encrypted-media; gyroscope; picture-in-picture"
    allowfullscreen></iframe>

Audio

El elemento <audio> funciona exactamente de la misma forma que el elemento <video> , con algunas pequeñas diferencias como se describe a continuación. Un ejemplo típico podría ser así: 

    
        <audio controls>
        <source src="resources/audio/elcantodellocopeterpan.mp3" type="audio/mp3">
        <source src="viper.ogg" type="audio/ogg">
        <p>Your browser doesn't support HTML5 audio. 
        Here is a <a href="viper.mp3">link to the audio</a> instead.</p>
        </audio>

Esto ocupa menos espacio que un reproductor de video, ya que no hay un componente visual; solo necesita mostrar los controles para reproducir el audio. Otras diferencias con respecto al video HTML5 son las siguentes:

  • El elemento <audio> no soporta los atributos width/height — de nuevo, no hay un componente visual,por no que no hay nada a lo que asignar un width o height (ancho o alto).
  • Tampoco es compatible con el atributo poster — de nuevo , no hay componente visual.

Insertar iframe de audio procedente de SoundCloud

La compañía SoundCloud (https://soundcloud.com/) permite insertar un reproductor de audio en nuestras páginas, para reproducir la canción que elijamos de entre todo el contenido que tienen. El procedimiento es análogo al que se hizo en el apartado anterior para insertar un video de youtube. Primero localizamos la canción a reproducir y obtenemos iframe con la fuente direccionando el archivo de audio a reproducir. 

                        
                <iframe width="100%" height="300" 
                    scrolling="no" 
                    frameborder="no"
                    allow="autoplay" 
                     src="https://w.soundcloud.com/player
                         /?url=https%3A//api.soundcloud.com/tracks/44570752
                         &color=%23ff5500&auto_play=false
                         &hide_related=false&show_comments=true
                         &show_user=true&show_reposts=false
                         &show_teaser=true&visual=true">
                </iframe>
