Creación de hipervínculos

¿Que es un hipervínculo?

Los hipervínculos nos permiten vincular documentos a otros documentos o recursos, vincular a partes específicas de documentos o hacer que las aplicaciones estén disponibles en una dirección web. Prácticamente cualquier contenido web se puede convertir en un enlace que, al pulsarlo (activarlo), dirija el navegador a la dirección web a la que apunta el enlace (URL).

Una URL (Localizador uniforme de de recursos) puede apuntar a archivos HTML, archivos de texto, imágenes, documentos de texto, archivos de audio o vídeo, y cualquier otra cosa que se pueda mostrar en la web. Si el navegador no sabe cómo manejar el archivo, te preguntará si lo quieres abrir (en cuyo caso la tarea de abrirlo y manejarlo se transferirá a la aplicación nativa instalada en el dispositivo) o si lo quieres descargar (en cuyo caso podrás ocuparte de él más tarde).

Anatomia de un enlace

Un enlace básico se crea incluyendo el texto o cualquier otro contenido que queramos convertir en un enlace dentro de un elemento ancla <a>, proporcionando a través del atributo href la dirección web hacia dónde queremos que apunte el enlace. La url que permite crear un hipervínculo al logo del sitio web de nuestro instituto es:
http://www.ies-azarquiel.es/images/logosazarquiel/logoiesfseif.png

El atributo title permite añadir información adicional sobre dicho enlace, como por ejemplo el tipo de información que contiene la página. Podemos usar el atributo title para completar el hipervínculo anterior de forma que muestre información contextual relacionada con la imagen.
El atributo target nos permite decidir si el hipervínculo se abrirá en una pestaña nueva (target="_blank")

El código que permite crear un hipervínculo a la imagen corporativa de nuestro instituto, cuya url hemos mencionado antes sería: 

                        
    <a href="http://www.ies-azarquiel.es/images/logosazarquiel/logoiesfseif.png" 
        title="Imagen corporativa del I.E.S. Azarquiel" 
        target="_blank">Logo del I.E.S. Azarquiel</a>
Prueba su funcionamiento pulsando en el siguiente hipervínculo:
Logo del I.E.S. Azarquiel

Convertir bloques de contenido en enlaces

Podemos convertir cualquier contenido en un enlace, incluso elementos de bloque y elementos en línea. Por ejemplo: si queremos convertir una imagen en un hipervínculo, usaremos un elemento <a> encerrando a la imagen.
Usamos la referencia a la imagen de nuestro instituto para convertirla en un enlace a la url: http://www.ies-azarquiel.es 

                        
        <a href="http://www.ies-azarquiel.es" title="Sitio web del I.E.S. Azarquiel" 
        target="_blank">
            <img src="http://www.ies-azarquiel.es/images/logosazarquiel/logoiesfseif.png"
                alt="Logo I.E.S Azarquiel" width="200">
        </a>

Urls y rutas

Una localizadora uniforme de recursos (URL, de las iniciales en inglés de «Uniform Resource Locator») es simplemente una secuencia de caracteres de texto que definen donde está situado algo en la web. Por ejemplo, la página de Mozilla está ubicada en https://www.mozilla.org/es-ES/.

Las URLs utilizan rutas para encontrar los archivos. Las rutas especifican dónde se encuentra el archivo que buscas dentro del sistema de archivos.

Al descomprimir el archivo comprimido que se adjunto con la presente práctica, se crea la estructura de directorios que da soporte a este sitio web en construcción.
El directorio raiz de la misma se llama HtmlTutorial.

En el directorio raiz se situa el archivo index.html que suele ser el punto de entrada a un sitio web.

Si queremos enlazar recursos (páginas, imágenes, etc) que están alojados en nuestro sitio web, tendremos que tener en cuenta si los mismos se hayan en el mismo directorio que la página desde la que vamos a enlazarlos o en un directorio distinto, que podrá estar situado por debajo o por encima dentro de la jerarquía de carpetas que contienen el contenido de nuestra web.

En el mismo directorio: Si queremos incluir un hipervínculo dentro del archivo index.html (el index.html del nivel más alto) que apunte al archivo texto.html, simplemente especificaremos el nombre del archivo al que hacemos referencia, porque se encuentra en el mismo directorio en el que se encuentra el archivo index.html desde donde lo queremos llamar. Por lo tanto, usamos la URL texto.html — veamos el código: 

                        
                    <a href="texto.html">

Bajando por la estructura de directorios:Creemos una carpeta a la que llamaremos "pdf" y situemos dentro de ella una copia del horario de grupo que puedes encontrar en el enunciado de la práctica, en la plataforma classroom. A continuación vamos a crear un hipervínculo para que al pulsar sobre él muestre el archivo horarioVS1ASIR.pdf en una pestaña nueva.

El hipervínculo se construiría así: 

    
        <a href="pdfs/HorarioVS1ASIR.pdf" title="Horario del grupo VS1ASIR" 
                target="_blank">Ver horario</a>
Ver horario

Si queremos que al pulsar sobre el hipervínculo se inicie la descarga del archivo de forma automática, el enlace apuntará a la carpeta que contiene el recurso y especificaremos el recurso a descargar mediante el atributo download. El enlace reescrito quedaría: 

    
    <a href="pdfs/horariovs1asir.pdf" download 
            title="Horario del grupo VS1ASIR" target="_blank">Descargar Horario VS1ASIR</a>

Descargar Horario VS1ASIR

Subiendo por la estructura de directorios:Hay veces que también necesitamos subir en la estructura de directorios para direccionar un recurso.
Un ejemplo lo tenemos en la hoja de estilos, donde hemos usado la siguiente propiedad asociada al elemento header: background-image: url(../img/html5.png);

Con ../ subimos un nivel en el arbol de directorios, desde estilo.css a la carpeta css, desde ahí con /img nos desplazamos a la carpeta img para acceder a la imagen html5.png.

Hipervínculo hacia una zona específica de un documento

Vamos a crear un hipervínculo que nos permita situarnos en el apartado "Anatomia de un enlace". Para ello hay que asignar previamente un atributo id al elemento hacia el que apuntamos. Lo hacemos así: 

    
        <h2 id="anatomiaenlace" class="azulcobalto">Anatomia de un enlace</h2>
Posteriormente para hacer referencia a este id concreto, lo añadiremos al final de la URL precedido por una almohadilla. 
    
    <a href="enlaces.html#anatomiaenlace" title="Anatomia de un enlace">Ir a anatomia de un enlace
    <a/>

Urls absolutas y relativas


Dos términos que encontrarás en la Web son URL absoluta y URL relativa:

URL absoluta: Hace referencia a una dirección definida por su ubicación absoluta en la web, esta incluye el protocolo, el nombre del dominio y la cadena de consulta
http://host:port/path?queryString#fragment

La queryString (cadena de consulta) permite enviar información adicional al servidor de forma que este construya la página con un contenido que depende de la información que es enviada a través de esa cadena de consulta.
Las páginas web construidas de esta forma se denominan páginas web dinámicas puesto que su contenido cambia dependiendo de los parámetros de consulta. La cadena de consulta está formada por pares de la forma variable1=valor1&variable2=valor2&.....&variablen=valorn
Ejemplo:
https://delphos.jccm.es/delphos/controlador?operacion=consultaralumno&nie=12345
Esta URL usa la cadena de consulta para informar al servidor de que la acción que quiere llevar a cabo es: consultaralumno y que el alumno a consultar es aquel cuyo nie es 12345

Las páginas de inicio de un sitio web (tipicamente index.html, index.php, index.jsp) a veces pueden omitirse puesto qe los servidores por defecto buscan en el directorio raiz un archivo con uno de esos nombres para servirlo. El archivo de inicio se puede establecer mediane políticas de uso del servidor web que usemos.
Puedes comprobar esto mediante el navegador embebido que carga visual studio code. Una vez e con el sitio que estamos realizando, si escribes en la barra de direcciones: http://127.0.0.1:5500/ verlas que la página que se muestra es la index.html. .
Una URL relativa: Hace referencia a una dirección que depende de la posición del archivo desde donde se utiliza — son las que vimos en la sección anterior.
